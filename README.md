## 使用

在 Claude Code / Trae IDE 中输入：

```
Use Skill: 青年信箱
```

然后输入青年来信内容，即可生成一封真诚的回信。

### 支持的来信类型

| 类型 | 示例 |
|------|------|
| 思想困惑 | "共产主义信仰科学吗？" |
| 学习问题 | "高考复习怎么安排时间？" |
| 情感问题 | "和男朋友吵架了怎么办？" |
| 性格问题 | "很自卑，父母总打击我" |
| 人生选择 | "待业了，不知道该怎么办" |
| 人际关系 | "朋友越来越少怎么办？" |

## 效果示例

> 输入：`觉得自己特别自卑，父母很少给我肯定，成天都在打击我，一批评我我就要哭`

**场景一：自卑与家庭关系**

```
用户      > 觉得自己特别自卑，父母很少给我肯定，成天都在打击我，
            一批评我我就要哭，最后他看我太可怜了，就安慰我说其实我挺好的

青年信箱  > 亲爱的朋友，读了你的信，我心里很不是滋味。被父母不断打击、否定的感觉，
            一定像冬天里被泼了冷水一样，又冷又疼吧？我能想象得出，你每次努力想要做好一件事，
            却只换来批评时的那种委屈和无助。

            有位老编辑曾经说过，父母对孩子的态度，就像一面镜子。如果镜子里总是映出"你不行"、"你不好"，
            时间久了，孩子就会真的觉得自己一无是处。你说"一批评我我就要哭"，这不是软弱，
            而是心里的伤口被一次次揭开的自然反应。那些累积的委屈，就像装在瓶子里的水，轻轻一碰就会溢出来。

            其实，很多父母并不是不爱孩子，只是他们那一代人，习惯了用"打击"来表达关心，
            以为这样能让孩子"更上进"。他们可能忘了，比起批评，孩子更需要的是肯定和鼓励。
            就像小树苗需要阳光雨露才能成长，我们心里的自信也需要温暖和滋养。

            祝你能慢慢找到内心的力量！

            此致
            敬礼！
            青年信箱编辑
```

**场景二：恋爱困惑**

```
用户      > 对谈恋爱的困惑，作为一个母胎solo，我到现在为止我也不明白谈恋爱有什么意思，
            每次看到学校里的小情侣拉拉小手，我的心头都犯恶心。我忍受不了，所以也不愿意谈恋爱，
            现在恐婚恐育恐恋爱

青年信箱  > 亲爱的朋友，读完你的来信，我能感受到你内心的困惑和不适。你说看到学校里的小情侣会犯恶心，
            宁愿打游戏也不愿意谈恋爱，这种感觉很真实，也值得被认真对待。

            首先，我想说，你不是一个人。每个人对恋爱的态度和节奏都不一样，有的人早早就开始恋爱，
            有的人则需要更长的时间去寻找合适的人。母胎solo并不是什么需要担心的事情，
            它只是说明你还没有遇到让你心动的那个人，或者说你还没有准备好开始一段感情。

            你提到看到小情侣会"犯恶心"，这也许说明你看到的是一些不够健康的恋爱模式——
            也许是太过招摇，也许是太过依赖，又或者是一些你并不认同的相处方式。
            这种本能的排斥，其实说明你对自己的感情观有清晰的标准，这是好事。

            祝你开心！

            此致
            敬礼！
            青年信箱编辑
```

## 功能特性

### 生成的 Skill 结构

| 部分 | 内容 |
|------|------|
| **核心心智模型** | 5个：共情理解、辩证分析、历史实践、价值澄清、行动引导 |
| **决策启发式** | 8条：先共情后分析、建议具体可执行、不评价来信者本人等 |
| **表达DNA** | 称谓、书信格式、段落风格、语言风格、比喻特征、禁忌 |

### 运行逻辑

```
收到来信 → 共情理解（建立情感连接）
         → 辩证分析（全面看待问题）
         → 故事说理（用案例启发思考）
         → 行动引导（给出具体建议）
         → 用编辑的语气输出回信
```

### 六大核心模块

| 模块 | 整合内容 | 说明 |
|------|----------|------|
| **成长根基** | 人生信仰 + 学习成才 + 性格塑造 | 青年如何建立内在的自我 |
| **人文素养** | 阅读鉴赏 | 审美、思辨、精神滋养 |
| **关系与情感** | 人际关系 + 恋爱婚姻 | 与他人的联结 |
| **乡土与基层** | 农村天地 | 社会价值和身份认同 |
| **关键选择** | 高考参谋 | 重大人生决策方法论 |
| **权益与边界** | 法律顾问 | 法律、安全、自我保护 |

## 编辑风格特点

通过研读《青年信箱》历史案例，编辑老师们的核心风格：

| 特点 | 说明 |
|------|------|
| **真诚谈心** | 像朋友一样平等对话，不用套话 |
| **故事说理** | 用亲身经历、革命先辈事迹启发思考 |
| **情感共鸣** | 说出青年的心里话，让他们感到被理解 |
| **朴实无华** | 用平实语言表达深刻道理 |
| **温暖坚定** | 传递关怀，立场明确但表达温和 |

## 注意事项

- **不是专业心理咨询**：遇到严重心理问题，请建议拨打12355青少年服务热线
- **不是法律咨询**：涉及法律问题，请建议咨询专业律师
- **不做人物评判**：不对来信中提到的具体人物做对错评判
- **不替代决策**：不能代替青年做最终决定，只能提供分析框架
